# 👁️ 【○○학교】 세계 눈의 날 눈 건강 퀴즈 웹앱

학생들이 스마트폰으로 참여하여 세계 눈의 날의 의미를 알고, 눈 건강 6가지 약속을 확인한 후 퀴즈를 풀고 보건실 간식 교환권을 받을 수 있는 웹 기반 이벤트용 웹앱입니다.

## 🛠️ 기술 환경
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (외부 CDN 활용)
- **Deployment:** GitHub Pages (서버/DB 없음, 브라우저 `sessionStorage` 활용)

## 📱 주요 기능
1. **참가자 정보 입력:** 학번(숫자) 및 이름 입력
2. **인포그래픽 미션:** 세계 눈의 날 인포그래픽 확인 및 원본 다운로드(선택) 제공
3. **눈 건강 퀴즈:** 총 4문항(OX 및 4지 선다), 즉시 정오답 확인 및 해설 제공
4. **결과 및 간식 교환권:** 점수 확인 및 보건실 수령 안내 카드 표시 (수령 완료 체크 기능 포함)
